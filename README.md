## Overview
```
This repository demonstrates an end-to-end enterprise integration project for a vendor payment acquisition process. It illustrates how an ERP system, a vendor web application, and a finance approval system exchange data through REST APIs to automate the generation of digitally signed payment acquisition documents.

The project is designed to showcase the responsibilities of an Integration Analyst, including business process analysis, API documentation, field mapping, database design, SQL validation, API testing using Postman, and integration troubleshooting.
```

## Business Scenario
```
Due to the complexity and inefficiency of current manual payment acquisition process, vendors are required to submit payment acquisition requests digitally instead of using paper-based forms.

In this scenario:

- Vendor master data is maintained within the ERP system.
- Vendors submit payment acquisition requests through a vendor web application.
- The request is transmitted to a finance approval system through REST APIs.
- The finance team reviews the request and generates a digitally signed payment acquisition document.
- The signed document is returned to the vendor web application and stored within the ERP system for future reference.

This integration improves operational efficiency, reduces manual processing, enhances document traceability, and minimizes human error.
```
